# Remit 功能原型 · 设计说明

原型是可点的那份：`index.html`（样式 `styles.css`，行为 `app.js`），双击打开。
静帧在 `shots/`：40 张 1440×900 @2x 的原型图（含四张状态图与八张编辑态），`shots/index.html` 是一张对照表。
这份文档是它的说明书：风格、导航、排版、动效、界面清单、组件清单、导出方式。

---

## 1. 方向

**纸面与铅笔。** 正文是纸，控件是铅笔；蓝色只做标记（光标、当前块、进度、可点），
其余靠留白与字阶分层。没有渐变、没有玻璃、没有装饰卡片叠层。

判断标准：**这一屏的目的，能不能在不读文字的情况下被看出来。**

## 2. 导航：两级

```
┌───────────┬──────────────────────────────────────────────────────────────┐
│ ◇ Remit   │ 写 / 笔记            [搜索 ⌘K]                     [⋯]        │ 60
│           ├──────────────────────────────────────────────────────────────┤
│ ▣ 今日  18│ 笔记   搜索   模板                                            │ 44
│ ✎ 写     8├──────────────────────────────────────────────────────────────┤
│ ▤ 读     3│                                                              │
│ ▥ 忆    18│                    内容（按屏幕取度量）                      │
│ ▨ 统计    │                                                              │
│ ⚙ 设置    │                                                              │
│           │                                                              │
│ ⚡ 制卡脚本 │                                                              │
│           │ 1,204 字 · 14 段 · 6 张卡 · 已保存                             │ 30
└───────────┴──────────────────────────────────────────────────────────────┘
    240                                                                 测宽
```

- **一级 = 我要做哪一类事**：今日 / 写 / 读 / 忆 / 统计 / 设置，外加一个插件页。
  动词命名，因为这是「记住」的三个动作：写下来、读进去、忆回来。
- **二级 = 这一类事里的哪一面**：写（笔记 / 搜索 / 模板）、忆（复习队列 / 卡片 / 卡片类型）、
  统计（总览 / 热力 / 预测）、设置（外观 / 复习 / 预算 / 快捷键 / 插件 / Agent / 更新 / 关于）。
  二级是文字 tab + 2px 下划线，下划线用 `scaleX` 长出来。
- **顶栏只放当前上下文**：面包屑 + 当前文档的动作（编辑 / 分栏 / 阅读、面板、查找、更多）。
  导航不再和动作抢同一行。
- **计数即待办**：今日 = 待读 + 待忆；写 = 笔记数；忆 = 到期卡数。
- **会话不占导航**：读会话、忆会话全屏接管，`Esc` 退出回到进入的地方。
- **降级**：≤980 左栏收成 64px 图标条；≤980 文档面板收起；≤760 边距 48→20、标题 34→30、
  评分两列、块手柄从左侧沟槽改为段落上方一行。

## 5. 动效

| 预设 | 参数 | 用在哪 |
|---|---|---|
| 反馈 | 120ms ease-out | hover、按下、开关、chip |
| 视图进入 | 180ms，上移 6px + 淡入 | 换屏、换 tab |
| 列表进入 | 180ms，每行 +24ms，最多 6 行 | 队列、笔记、大纲 |
| 内容展开 | 180ms，上移 6px + 淡入 | 答案、总结、查找条 |
| 浮层 | 180ms scale(.97→1) | 菜单、对话框 |
| 进度增长 | 260ms width 0 → 目标 | 阅读进度、预算条、热力 |

只动 `opacity` 与 `transform`（进度条是唯一例外，且只在挂载时跑一次）。
`prefers-reduced-motion: reduce` 下全部归零，布局不变。

## 8. 一条能走通的流

```
今日 → 开始 → 读会话（J/K 移块）→ E 摘录 → 子笔记（带 [[标题#^块]]）
                                     ↘ C 挖空 → cloze 卡
     → 忆会话 → 答不上来 → 回到原文那一段
```

摘录会同时改三处：库里多一篇笔记、原文反链多一行、块沟槽多一个摘录标记——
这是「一套模型」最直接的证据。

## 9. 取舍

- 只用系统 UI 字体栈（PingFang / SF），因为原生应用就是这么排的。
- 不配图：内容是文字、列表、引用、代码、表格、公式；图表用 SVG 现画。
- 表格单元格只读（归 #218）；资产页只列文件，不假装缩略图。
- 参考答案里的卡片数、到期数、热力格都由同一个数据源算出来，不写死互相矛盾的数字。

## 10. 导出与深链接

`shots/` 里是 40 张 PNG（2880×1800，即 1440×900 @2x），由 `index.html` 按深链接逐屏渲染，
不是画出来的。其中四张是状态图：**悬停**（行内动作显形）、**选中**（勾选 + 行底色 + 计数）、
**占比**（统计的时间配比，局部裁切）、**空态**（阅读队列读空之后）。状态图用 CDP 真实移动指针
与点击生成，不是给元素加一个假 class。`shots/index.html` 是它们的对照表。

**深链接**：`index.html#/area/sub[/note]?mode=&tag=&theme=`

| 例子 | 落到 |
|---|---|
| `#/today` | 今日 |
| `#/write/doc/n1?mode=read` | 打开 n1 的阅读态 |
| `#/write/doc/n1?mode=split` | 分栏 |
| `#/recall/cards` | 卡片表 |
| `#/today?theme=dark` | 墨色外观下的今日 |

会话与浮层没有路由，靠初始化后调用 `openReading()` / `openReview()` / `openPalette()` /
`openCardDetail()` / `openScope()` 复现——导出脚本就是这么做的。

**边界**：PNG 是静态的，点不了；想让人点就用 `index.html`。深链接只读地址栏，
不改写它，所以在只读沙箱里也不会坏。

## 11. 八处融合断裂与改造清单

3 合 1 的价值在「同一个块同时是笔记单位、阅读位置、卡片宿主」。下面八处曾经断裂，

| # | 断裂 | 改成了什么 | 依赖 |
|---|---|---|---|
| 1 | 沟槽只显示卡数 | 徽章带状态（`due` / `new` / `later` / `lost`），边框形状与 `!` 前缀双编码，`aria-label` 读出「2 张今天到期，1 张新卡」；点击打开**块检查器** | ADR 0002 生命周期 + 引用态 |

## 12. 白板：插件画布上的双向引用

白板是「非核心但可以交给插件」的第一个实例：它不新增数据模型，只存**指向块的引用**。

- 一个节点 = 一个 `{note, block}` 引用 + 画布坐标。删掉节点不删笔记，删掉块则节点退化为「源块已不在」。
- **节点 → 块**：点节点，打开那篇笔记的阅读态并滚到那一段。
- **块 → 节点**：块的 `⋮⋮` 菜单与块检查器各有一个「在白板里定位」，跳回画布并给节点加环。
- 画布本身不提供编辑能力（不新增块、不改文本）——它是阅读面的另一种视角，不是第二个编辑器。

编辑态静帧（插入菜单、块菜单、选区动作条、卡片编辑器、导出、导入向导、快捷键）此前只有界面没有图，
现在补齐：`shots/30`–`shots/36`。

## 13. 忆：六个页，一个筛选

| 页 | 结构 |
|---|---|
| 队列 | 今日容量（新 / 学习中 / 复习三段占比）+ 六个筛选 + 保存的搜索 + 按笔记分组 + 热力 |
| 卡片 | 左侧三组筛选（状态 / 类型 / 引用）+ 搜索语法 + 可切列 + 批量动作 |
| 类型 | 主从工作台：左选类型（含插件供给的），右侧字段、模板、两面预览、回退说明 |
| 预设 | 学习步、每日上限、败笔处理、难卡阈值、断链行为 |
| 历史 | 今天的时间线 + 评分分布 + 本周汇总 |
| 断链 | 丢失引用的卡片、逐块重连、冻结与解冻 |

**「难卡」不是一个页面，是一个筛选。** 它由 FSRS 的败笔次数派生（`lapses ≥ 3`），
在队列的 chip、卡片的侧栏、搜索语法 `is:hard` 三处是同一个条件。曾经它占过一整页，
那是把"一个属性"当成了"一种东西"。

**卡片类型可以由插件供给。** 「模板：问答」插件启用时，类型页多出一种 `问答`（字段：问 / 答），
标注「插件 · 模板：问答」；关掉插件它就从列表、筛选、制卡入口一起消失。宿主只认字段表与
两段模板，不认类型来自谁。

**卡片浏览**补齐到可用：搜索语法（`is:` / `type:` / `tag:` / `note:`，空格为「与」）、
token 行回显当前条件、按提示 / 笔记 / 类型 / 状态 / 间隔 / 重来 / 到期排序、列可开关、
批量动作（暂停 / 改到期 / 改类型 / 加标签 / 埋藏同类 / 冻结 / 删除）。
