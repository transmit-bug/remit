## 2. 横切规则

每个切片都适用，不再逐票重复。

- **PR 单位**：每屏提取一个 PR（ADR 0009），每票一个 PR（`docs/engineering/conventions.md`）。
- **验证**：`go build ./...`、`go test ./...`、`CGO_ENABLED=0 go test ./...`、
  `go tool mygo vet .`；动了文案再跑 `go tool mygo i18n check .`。
- **官方件优先**：先按 `mygo-components` skill 对 v0.8.1 的清单核一遍，need→widget 表随
  PR 描述附上；手写要写理由。
- **i18n**：用户可见字符串 `locales/en.json` 与 `locales/zh-Hans.json` 同改，然后
  `go tool mygo generate` 重建 `locales/catalog_gen.go`。
- **依赖方向**：`internal/core` 不 import `mygo/ui`；屏包不 import `internal/ui`、不碰
  store、不 import 兄弟屏（ADR 0001 / 0004 / 0009）。
- **时间注入**：core 逻辑不读时钟，`store.Options.Now` 是唯一的钟。
- **断言**：文本、盒子、焦点、键盘路径；不建像素基线。`tt.Image()` 只做人工过目。
