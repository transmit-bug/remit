# 块工具：手柄、菜单与当前块

笔记正文里的块操作入口。`richtext` 继续拥有文字、选区和撤销；宿主只把
`Document.VisibleParagraphs()` 的盒子画成左侧沟槽，动作仍写回同一个
`richtext.Document`，保存走既有的 `SaveDocument`。

## 已定的交互

- **手柄**：指针进入可见段落的左侧 48 DIP 沟槽，或该段落是光标所在块时，
  显示 `+` 与拖动柄（键盘因此仍能到达）。拖动柄按下拖动排序，单击打开块
  菜单；手柄与段落第一行对齐，段落滚出视野后不再显示。
- **`+`**：在该段落之后插入一个正文空段落，光标进入新段落。
- **拖动 / 上下移**：拖动柄落到另一块的沟槽，或菜单选上移 / 下移，按块 ID
  移动整块；卡片跟着块走，不按位置换源。
- **块菜单**：菜单打开后锚点保留，即使指针移进菜单也不消失。提供在下方
  新增、复制、上移、下移、删除，以及转成正文 / 标题 1 / 标题 2 / 标题 3 /
  无序列表 / 有序列表 / 引用 / 代码块。
- **删除**：最后一块不可删。有 live 卡片的块先弹确认，说明多少卡片会失去
  来源且复习历史保留；确认后删除，并用 toast 报告损失数量。暂停或已冻结的
  卡片不计入损失。
- **当前块**：有悬停段落时标它，否则标光标所在段落。浅底在文字下方，左侧
  2 DIP 强调色竖线；文字始终是最上层。
- **`/` 插入**：在空段落开头输入 `/` 打开过滤菜单；↑/↓ 选，Enter 执行，
  Esc 关闭并保留已输入文字。命令含标题、列表、引用、代码块、公式（块级 /
  行内）、图片和表格。
- **图片**：菜单走注入的文件选择器，文件仍按 #152 的口径落入
  `assets/<sha>.<ext>`，笔记只留相对引用。
- **表格**：插入一个 3 列 GFM 表格骨架。编辑器把表格显示为只读占位块，
  保存时写回原始 GFM，避免 `richtext` 把表格拍平；单元格原地编辑归 #218。
- **身份**：插入与复制不改动其它块的 ID。未变块按文本锚定，编辑块在相邻
  锚点之间按顺序配对；移动、删除与表格占位按块 ID 写回，只有真正新增的块
  铸造新 ID。

## 本片不做

- 多块选择与批量动作。
- 表格单元格、插行插列的原地编辑（#218）；当前表格块只读。
- 分隔线：`richtext` 会丢弃 thematic break，暂不提供会静默丢失的入口。

## 验收

- headless 测试覆盖：悬停或光标所在块出现手柄、`+` 插入后其它块 ID 不变、
  菜单转换落到文档并保存、上下移与拖动保持块 ID、删除前按卡片数告警、取消
  删除不写库。
- `/` 菜单覆盖：过滤、Enter 执行、公式插入、图片选择器、表格插入；表格在
  编辑、保存、重开后仍是 GFM 源，表格后的块 ID 不变。
- 默认 1024×720 与最小 720×520 下，手柄在纸面沟槽内，不盖住正文，菜单可
  打开并选择。
