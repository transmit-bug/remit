# 块工具：手柄、菜单与当前块

笔记正文里的块操作入口。`richtext` 继续拥有文字、选区和撤销；宿主只把
`Document.VisibleParagraphs()` 的盒子画成左侧沟槽，动作仍写回同一个
`richtext.Document`，保存走既有的 `SaveDocument`。

## 已定的交互

- **手柄**：指针进入可见段落的左侧 48 DIP 沟槽，或该段落是光标所在块时，
  显示 `+` 与 `⋯`（键盘因此仍能到达）。手柄与段落第一行对齐；段落滚出
  视野后不再显示。
- **`+`**：在该段落之后插入一个正文空段落，光标进入新段落。
- **块菜单**：菜单打开后锚点保留，即使指针移进菜单也不消失。首片提供：
  在下方新增、复制块，以及转成正文 / 标题 1 / 标题 2 / 标题 3 / 无序列表 /
  有序列表 / 引用 / 代码块。
- **当前块**：有悬停段落时标它，否则标光标所在段落。浅底在文字下方，左侧
  2 DIP 强调色竖线；文字始终是最上层。
- **身份**：插入与复制不改动其它块的 ID。未变块按文本锚定，编辑块在相邻
  锚点之间按顺序配对；只有真正新增的块铸造新 ID。

## 首片不做

- 拖动排序、上移 / 下移、删除块。它们需要更完整的块身份与卡片损失提示，
  单独成片。
- `/` 插入菜单，以及表格、图片、公式的插入入口。它们跟随 #132 的后续片。
- 多块选择与批量动作。

## 验收

- headless 测试覆盖：悬停或光标所在块出现手柄、`+` 插入后其它块 ID 不变、
  菜单转换落到文档并保存。
- 默认 1024×720 与最小 720×520 下，手柄在纸面沟槽内，不盖住正文，菜单可
  打开并选择。
