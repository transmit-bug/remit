# UI 重设计 · 笔记应用该有的样子

一张地图。上一轮把组件换成了官方件（`docs/specs/ui-composition.md`），但界面仍然"简陋"：
**组件都对，设计没做**。这份稿子先定义"一个笔记应用应该有哪些要素"，再定义视觉系统，最后分期。

参照物：留白（liubai）的 `DESIGN.md`/`PRODUCT.md`（MIT，仅参考结构与规则，不抄代码——它跑在 web 视图 + CodeMirror，Remit 跑在原生 `ui`）。

> **口径（按今日代码校正）**：状态列以 `docs/specs/ui-inventory.md`（v0.8.1）+ `internal/ui` 为准。
> `缺` 是未做，不是回归；`半` 是做了但与本稿不一致。P0 的要素已经落地，§2.1 的
> “标题进顶栏、保存状态在顶栏”已改判为“标题在纸面首行、保存状态在状态行”。

## 1. 为什么上一轮不够

| 现象 | 根因 |
|---|---|
| 标题和正文是带边框的输入框 | 组件默认外观被当成设计；`richtext.Theme` 从未设置 |
| 正文 13px / 行高 1.4 / 无段距 | 没有排版层级（type scale） |
| 格式条字形大小不一、分组靠空隙 | 没有控件规范（34px 命中区、12px 标签、分隔线） |
| 三行控件互相打架 | 没有框架（frame）概念：顶栏 / 格式条 / 页面 / 状态行 |
| 大片空白、空态一句话 | 没有内容要素：大纲、状态行、块手柄、预览、搜索 |
| 复习总结是一张漂着的小卡 | 没有数据层级（大数字 + 小标签） |

结论：需要一次**视觉系统 + 要素补齐**的重设计，而不是再换一次组件。

## 3. 视觉系统

§3 是目标；token 名与数值已按 `internal/ui/design` 校正，标“今天”的例外以代码为准。

### 3.1 颜色角色

角色名直接落在 `design.Palette` 的键上，不另起一套名字：

| 角色 | token | 用途 |
|---|---|---|
| Page | `Palette.Page` / `theme.Background` | 窗口底色（页面之外） |
| Paper | `Palette.Card` / `theme.Surface` | 顶栏、格式条、纸面、状态行 |
| Float | `Palette.Card` + `ShadowPanel`（`kit.Panel`） | 侧栏、菜单、对话框、气泡 |
| Sunken | `Palette.Sunken` | 输入框、代码底 |
| Hairline | `theme.Border` / `Palette.Border` | 所有 1px 分隔与容器边 |
| Ink / Pencil / Faint | `theme.Text` / `theme.TextMuted` / `TextFaint` | 正文 / 次要 / 提示 |
| Mark | `theme.Accent` | 光标、当前大纲项、块手柄、选中行；可作线条，也可作浅底（强调色 14–16% 混纸面） |

**细线规则**：相邻表面用 1px 细线 + 至多一级明度差分开；只有浮起的层用阴影。

### 3.2 排版

| 名称 | 目标字号 / 行高 | 用途 |
|---|---|---|
| Display | 34 / 1.35，600 | 文档标题 |
| Headline | 27 / 1.4，600 | H2 |
| Title | 22 / 1.45，600 | H3 |
| Body | 18 / 1.85，400 | 正文 |
| Chrome | 13 / 1.2，400 | 控件、菜单、顶栏 |
| Label | 12 / 1.2，400 | 分段项、侧栏行 |
| Caption | 11 / 1.2，400 | 状态行、大纲 |

正文行宽：760px 纸面 − 48×2 边距 ≈ 664px ≈ 37 个汉字。

行高是目标值。今天的实现：正文 18（`TypeBody × 1.2`）/ 1.85，标题按正文的 1.9 / 1.5 /
1.22 倍（34 / 27 / 22），段距 0.95；chrome 用 `TypeTitle 22 / TypeHeading 17 /
TypeBody 15 / TypeSmall 13`，随桌面文本缩放，文档字号今天**不随**（`noteFont` 读常量）。

### 3.3 间距与形状

间距：4 / 8 / 12 / 16 / 24 / 32（`SpaceXS`…`SpaceXXL`）；纸面左右边距 48（`Gutter`）。
组内 8–12，组间 16–24。
圆角：控件 6、卡片 10、面板 14（`RadiusControl/Card/Panel`），热力格 3（`RadiusBar`）。
控件：命中区 ≥ 34（`Control` 32 + 2），输入框 ≥ 32（`Control`），格式条 44（`BarHeight`），分段项随内容。
图标：Lucide（vendored v0.460.0），2 描边，16 / 20 / 24（`IconSmall/Medium/Large`），颜色随文字。

### 3.4 状态

hover 立即、按下即暗；焦点 2px 环、外 2px；禁用半透明；选中 = 浅底 + 标记色文字（大纲、侧栏）。
空态：图标 20 + 一句话 + 一个动作。加载：骨架或 `ui.Spinner`。错误：`c.Toast` + 就地提示。

## 4. 屏幕布局

### 4.1 笔记（编辑）

```
┌─ 顶栏 ─────────────────────────────────────────────────────────────┐
│ Remit │ 笔记 复习 浏览 统计 设置 │ 编辑 分栏 阅读 │ 面板 │ ⋯        │
├─ 格式条 44 ────────────────────────────────────────────────────────┤
│ 标题⌄ │ B I U S <> │ • 1. ☐ ❝ {} │ 🔗 │   （P1：＋ ↶ ↷ 表 图 Σ）  │
├─ 工作区 ───────────────────────────────────────────────────────────┤
│ ┌ 笔记列 260 ┐ ┌──── 纸面 760 ────┐ ┌─ 面板 ──────────────┐        │
│ │ 搜索    ＋ │ │ 独立开发周记     │ │ 大纲 / 反链          │        │
│ │ 今日    3 │ │                  │ │ ▸ 本周进展  ←当前    │        │
│ │ #标签      │ │ 这周把「随手记」 │ │   发布清单           │        │
│ │ 笔记…      │ │ [卡片徽章条]     │ │                      │        │
│ └────────────┘ └──────────────────┘ └──────────────────────┘        │
├─ 状态行 ───────────────────────────────────────────────────────────┤
│            1,204 字 · 12 段 · 6 张卡 · 已保存                      │
└────────────────────────────────────────────────────────────────────┘
```

- 笔记列是 `Split` 的第一栏（默认 260，可拖、宽度记住）；“抽屉 + ☰”未做，
  `narrowWindow` 只收起右侧面板。
- 大纲在面板里，与反链共用一个 `Segmented`；随 `narrowWindow` 收起。
- 状态行居中在纸面宽度下，没有时刻，也没有 ⌘K 提示。
- 格式条 44px，居中，分组用 `ui.Divider`；溢出收进 `⋯`。插入 / 撤销 / 重做 / 表格 /
  图片 / 公式仍缺。

### 4.2 笔记（分栏 / 阅读）

分栏：左编辑右阅读，中线 1px；阅读栏只放 Markdown，无标题、无状态行。
阅读：纸面整幅，无格式条、无手柄；顶部是标题（`TypeTitle` 22，不是 34 的 Display），
没有状态行。

### 4.3 复习

```
┌───────────────────────────────────────────────┐
│ 2 张剩余 · 今日 12/20        ▓▓▓▓▓░░░░░        │
│                                               │
│           What is spaced practice?            │  卡面 Markdown
│                                               │
│           [ 显示答案 ]                        │
│                                               │
├───────────────────────────────────────────────┤
│  [1 重来][2 困难][3 良好][4 容易]   U 撤销  S  │
└───────────────────────────────────────────────┘
```

完成总结（已建）：宽 520 卡片、内边距 32；标题行图标 + 「今日复习」；三格大数字
（复习 / 明日 / 记住率，`kit.Stat`）；插件文案每行一段（公式经 `maths.Render`，空行跳过）；
主按钮「回到笔记」。`tone: celebrated` 时卡片有一次入场动效，`quiet` 静止，两者都随
reduce-motion 归零。

### 4.4 浏览 / 统计 / 设置

浏览：`ui.Table`，列 = 提示 / 笔记 / 状态 / 到期；表头排序、行多选、右键菜单（待 S3，今天是
`ListState` + 手拼行）。
统计：纸面上三块：热力图、保留率、预测；每块 `TypeHeading` 17 标题 + `TypeSmall` 13 说明。
设置：`Form` + `Fieldset`；今天四组：Agent、更新、全局快捷键、每日提醒，组间 16。外观
（主题随系统）与复习（保留率等参数在 `remit.json`）都没有界面。

## 5. 实现映射（组件优先）

| 要素 | 组件 |
|---|---|
| 顶栏 / 格式条 | `ui.Toolbar` + `ui.Divider` + `ui.Segmented` + 图标 `Button` + `MenuButton` |
| 纸面 | `ui.Scroll` + 居中的 `Column`（`MaxWidth` + `Padding`） |
| 正文排版 | `richtext.Theme`（字号、标题、引用、代码、段距）+ `EditorOptions.Font` |
| 块手柄 | `Document.VisibleParagraphs()` + `ui.MenuButton`（`ParagraphBox` 定位） |
| 状态行 | `ui.Row` + `ui.Text`（11px） |
| 侧栏搜索 | `ui.SearchField` |
| 侧栏行 | `ui.Sidebar` + `SidebarItem` + `Badge`（标题 + 卡片数；摘要第二行是待做） |
| 大纲 | `ui.Outline` + `OutlineState`（光标所在标题即当前项） |
| 卡片徽章条 | `ui.ScrollHorizontal` + 徽章 `Button` + 字段编辑 `ui.DialogBase` |
| 卡片表格 | `ui.Table` |
| 总结统计 | `kit.Card` + `kit.Stat` + `PrimaryButton` |
