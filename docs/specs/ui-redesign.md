# UI 重设计 · 笔记应用该有的样子

一张地图。上一轮把组件换成了官方件（`docs/specs/ui-composition.md`），但界面仍然"简陋"：
**组件都对，设计没做**。这份稿子先定义"一个笔记应用应该有哪些要素"，再定义视觉系统，最后分期。

参照物：留白（liubai）的 `DESIGN.md`/`PRODUCT.md`（MIT，仅参考结构与规则，不抄代码——它跑在 web 视图 + CodeMirror，Remit 跑在原生 `ui`）。

## 1. 为什么上一轮不够

| 现象 | 根因 |
|---|---|
| 标题和正文是带边框的输入框 | 组件默认外观被当成设计；`richtext.Theme` 从未设置 |
| 正文 13px / 行高 1.4 / 无段距 | 没有排版层级（type scale） |
| 格式条字形大小不一、分组靠空隙 | 没有控件规范（34px 命中区、12px 标签、分隔线） |
| 三行控件互相打架 | 没有框架（frame）概念：顶栏 / 格式条 / 页面 / 状态行 |
| 大片空白、空态一句话 | 没有内容要素：大纲、状态行、块手柄、预览、搜索 |
| 复习总结是一张漂着的小卡 | 没有数据层级（大数字 + 小标签） |

结论：需要一次**视觉系统 + 要素补齐**的重设计，而不是再换一次组件。

## 3. 视觉系统

### 3.1 颜色角色

沿用 `design.Palette`，只补三个层次的名字，让"纸面"成立：

| 角色 | 用途 |
|---|---|
| `Ground` | 窗口底色（页面之外） |
| `Paper` | 纸面：顶栏、格式条、正文页、状态行 |
| `Float` | 浮起：侧栏、菜单、对话框、气泡 |
| `Hairline` | 所有 1px 分隔与容器边 |
| `Ink` / `Pencil` / `Faint` | 正文 / 次要 / 提示 |
| `Mark` | 标记色：光标、当前大纲项、块手柄、选中行，**只作线条** |

**细线规则**：相邻表面用 1px 细线 + 至多一级明度差分开；只有浮起的层用阴影。

### 3.2 排版

| 名称 | 字号 / 行高 | 用途 |
|---|---|---|
| Display | 34 / 1.35，600 | 文档标题 |
| Headline | 27 / 1.4，600 | H2 |
| Title | 22 / 1.45，600 | H3 |
| Body | 18 / 1.85，400 | 正文 |
| Chrome | 13 / 1.2，400 | 控件、菜单、顶栏 |
| Label | 12 / 1.2，400 | 分段项、侧栏行 |
| Caption | 11 / 1.2，400 | 状态行、大纲 |

正文行宽：760px 纸面 − 48×2 边距 ≈ 664px ≈ 37 个汉字。

### 3.3 间距与形状

间距：4 / 6 / 8 / 12 / 16 / 24 / 48。组内 6–8，组间 16–24。
圆角：控件 6、组内 5、菜单 9、对话框 13；分段轨道 7 + 内边距 2。
控件：图标按钮 34×34，图标 18–19；输入框 34 高；分段项 30 高。
图标：Lucide，1.6 描边，14–19px，颜色随文字。

### 3.4 状态

hover 立即、按下即暗；焦点 2px 环、外 2px；禁用半透明；选中 = 浅底 + 标记色文字（大纲、侧栏）。
空态：图标 20 + 一句话 + 一个动作。加载：骨架或 `ui.Spinner`。错误：`c.Toast` + 就地提示。

- 侧栏是抽屉：宽 ≥1180 时停靠 290px，否则浮在纸面上；`☰` 开合。
- 大纲在纸面旁留出 200px 以上且 ≥2 个标题时显示；分栏/阅读下变成 `☰` 旁的浮层。
- 格式条 44px，居中，分组用 `ui.Divider`；溢出收进 `⋯`。

### 4.2 笔记（分栏 / 阅读）

分栏：左编辑右阅读，中线 1px；阅读栏同纸面宽度与排版。
阅读：纸面整幅，无格式条、无手柄；顶部显示标题与状态行。

插件文案一段；主按钮「回到笔记」。

### 4.4 浏览 / 统计 / 设置

浏览：`ui.Table`，列 = 提示 / 笔记 / 状态 / 到期；表头排序、行多选、右键菜单。
统计：纸面上三块：热力图、保留率、预测；每块 20px 标题 + 12px 说明。
设置：`Form` 分组卡片（外观 / 复习 / Agent / 更新），组间 24px。

## 5. 实现映射（组件优先）

| 要素 | 组件 |
|---|---|
| 顶栏 / 格式条 | `ui.Toolbar` + `ui.Divider` + `ui.Segmented` + 图标 `Button` + `MenuButton` |
| 纸面 | `ui.Scroll` + 居中的 `Column`（`MaxWidth` + `Padding`） |
| 正文排版 | `richtext.Theme`（字号、标题、引用、代码、段距）+ `EditorOptions.Font` |
| 块手柄 | `Document.VisibleParagraphs()` + `ui.MenuButton`（`ParagraphBox` 定位） |
| 状态行 | `ui.Row` + `ui.Text`（11px） |
| 侧栏搜索 | `ui.SearchField` |
| 侧栏行 | `ui.Sidebar` + `SidebarItem` + `Badge`（摘要用第二行 `Pencil`） |
| 大纲 | `ui.Outline`（当前项 = `List.Selected` 或 `Prefix` 自绘标记） |
| 卡片表格 | `ui.Table` |
| 总结统计 | `kit.Stat` |
