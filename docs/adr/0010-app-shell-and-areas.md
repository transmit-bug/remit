# ADR 0010 — 应用骨架、六个区域与会话层

- **Status:** accepted
- **Date:** 2026-11-10
- **Related:** #212, #128, #201, #206, #129, `docs/specs/ui-redesign-v2.md` §1.2/§1.8/§2/§6.1/§10.2, ADR 0004, ADR 0009
- **Supersedes:** 五主页面的形态与 `mode` 枚举导航（见「取代」）

## 背景

今天的窗口是一行 `ui.Toolbar`（brand + 五个 tab + 上下文）加一个 `mode` 枚举：笔记 / 复习 /
浏览 / 统计 / 设置。3 合 1 把产品合成一个工作台（`docs/specs/three-in-one.md` §2），这一形态装不下
主流程「今日 → 开始 → 读 → 摘 → 忆 → 回原文」：#206 把默认首屏判为混合队列（今日），#212 要求
一级回答「我要做哪一类事」，二级才回答「这一类里的哪一面」。当前代码与原型在这三处的差距记在
`docs/specs/ui-redesign-v2.md` §0.3。

## 决定

### 一个工作台、六个区域、一条会话层

一级是六个区域——**今日 / 写 / 读 / 忆 / 统计 / 设置**——加轨道底部一条**插件页分组**。
区域回答「做哪一类事」，子页回答「这一类里的哪一面」：

| 区域 | 子页 |
|---|---|
| 今日 | 无 |
| 写 | 笔记 / 搜索 / 标签 / 摘录树 / 资产 / 模板 |
| 读 | 队列 / 归档 |
| 忆 | 队列 / 卡片 / 类型 / 预设 / 历史 / 断链 |
| 统计 | 总览 / 热力 / 预测 |
| 设置 | 外观 / 复习 / 预算 / 快捷键 / 插件 / Agent / 更新 / 关于 |

清单、路由与每面的数据源见 `docs/specs/ui-redesign-v2.md` §1.8、§3。默认首屏是**今日**
（§10.2 第 1 条）：它是对「复习队列是默认首屏」的改判，理由与队列形状写在 §1.2、§5.1。

### 会话不占区域

阅读会话与复习会话全屏接管，不占区域、不进导航；`Esc` 退出并回到进入处的那个控件。
浮层（菜单、对话框、命令面板）同样不是区域。骨架因此是导航轨 240 + 顶栏 60 + 子导航 44 +
状态行 30，窄窗把轨道收成 64（§2.1）。

### 路由是四个字段，`mode` 是派生值

`App` 的 `mode` 枚举拆成 `area` + `sub` + `session` + `overlay`（§2.7）。`mode` 字段保留，但从三者
算出，唯一写入点是 `syncMode()`，由 `App.setArea` / `App.setSub` / 会话开关调用；它的取值仍是
`notes / review / browse / stats / settings / ""`。插件 `when` 的 `mode` 取值表不变，新增的上下文键是
`area` 与 `sub`（兼容添加，§6.3）——既有 `when` 表达式不会因 IA 改动而静默变真或变假。

深链接是 `#/area/sub[/id][?mode=|tag=|q=]`；`internal/deeplink` 新增 `today` / `read` / `recall`
三种，既有的 `note` / `card` / `queue` / `search` 不动，`App.ShowArea` 是它与命令面板共用的入口
（§2.7、§5.7）。

### 折叠是产品规则

`BreakpointNarrow 980`、`BreakpointSmall 760`、最小窗 720×520；规则落在 `internal/ui/design` 的
断点常量与各屏的开关里，不写进屏的 `Width()`。最小窗下整窗不出现横向滚动（§2.5）。

### 插件页是一组，不是一屏

`contributes.pages[]` 的页面在轨道底部单独一组：有页面就有这一组，没有页面整段不建，
`nav: "hidden"` 的页面不进轨道（§6.1）。组内排序归 #129，本 ADR 只定「有一组」。

## 理由

- 一级按「做哪一类事」分，三套动作不需要三套导航；今日是唯一一张把读、摘、忆放在同一张待办上的
  屏（#206）。
- 会话层让「读一篇」「过一轮卡」保持全屏、不被打断，同时不把它们塞进一级，避免回到两条并列入口。
- `mode` 派生而非状态：既有代码与测试仍读这个字段，而插件契约不动（§2.7、§6.3）。

## 后果

- `internal/ui/window.go` 的 `shortcuts` 与 `internal/ui/window_test.go` 同改：`⌘1…⌘6` =
  今日 / 写 / 读 / 忆 / 统计 / 设置，其中 `⌘1…⌘3` 从「复习 / 笔记 / 浏览」改判（§2.8）。
- 子页按 ADR 0004/0009 落在 `internal/ui/screens/<name>/`，`internal/ui` 只留装配；今日新增
  `screens/today`（§1.2）。区域计数继续由 `App.queueCounts` 供托盘与提醒（§5.1）。
- 焦点顺序固定为轨道 → 顶栏 → 子导航 → 舞台 → 状态行（不可聚焦）→ 浮层，浮层关闭时焦点还给
  打开它的控件（§2.6）。
